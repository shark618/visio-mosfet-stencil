# Visio MOSFET stencil — diode asset

此仓库包含为 Visio 制作的功率 MOSFET 体二极管（body diode）矢量图（SVG），你可以下载并在 Visio 中插入并保存为模具（stencil）。

文件列表：
- mosfet_body_diode.svg — 单独的二极管符号（SVG），可直接插入 Visio，或转换为 Visio 形状并保存为 .vssx。

如何在 Visio 中使用 SVG：
1. 将 mosfet_body_diode.svg 下载到本地。
2. 在 Visio 中选择 Insert → Pictures → 此设备，选择 SVG 文件。Visio 会以矢量对象插入。
3. 若要把它变为可复用的 Visio master：选中图形，右键 → Group/Ungroup（可能需多次取消组合）直到可以选中单条路径；然后打开 Shapes 窗格（More Shapes → New Stencil），将形状拖入新模具；右键新模具 → Save As，保存为 .vssx 并放入 `Documents/My Shapes` 目录。

参考资源（可下载更多 Visio 电子符号）：
- Paul Herber — Electronics shapes for Microsoft Visio: https://www.paulherber.co.uk/visio-electronics/
- GitHub — visioStencils: https://github.com/bhdicaire/visioStencils
- Microsoft Visio shapes search: In Visio → More Shapes → Search Shapes
